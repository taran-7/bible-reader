## Decisions

1. An entry is stored in the translation's own numbering (`translation`, `book`, `chapter`, `verse`; `verse = 0` in the database means a chapter without a verse), because a click reopens exactly that translation: no mapping needed. Identity (dedupe) is translation + book + chapter + verse.
2. Recording lives in `ReaderViewModel`: `open(_:focus:)` covers reference search, search results, bookmarks, draft links and chapter navigation; selecting a verse (`anchorVerse`) covers clicks. Both are idempotent thanks to dedupe, so the focus-then-select echo after a jump does not duplicate.
3. Persistence: one table `visit` with an autoincrement id as the order; recording is delete-same-key, insert, trim to the newest 50, in one transaction. Errors are ignored (a convenience, like the saved position); without a database the list lives in memory. Unknown translation codes are dropped on load.
4. A row shows the book's full name in the translation's language (`От Иоанна 3:16`, `Від Івана 3:16`, `John 3:16`), the same as the clipboard quote; no translation label (the language tells it).
5. `openVisit` switches translation with `keepLocationOnSwitch` (no numbering remap: the entry is already in that translation's numbering), then `open`. Compare is re-run for the entry's verse with the previous columns, the entry's translation first; the parallel view needs no work because it rebuilds from the new chapter. If the entry's translation was the parallel one, the old main translation takes its place.
6. Layout: the panel is a column in an `HStack` next to the reading area (not an overlay), so nothing the reading area draws can cover it. In `ChapterView` the selection buttons are an overlay of the (column + reserved margin) group, which is then centered, so they stand right after the ~75-character column; in the parallel view the group is full width and they stay at the right edge.
7. Visibility: shown unless Drafts / Illustrations are open; then `historyAlongsidePanels` (a persisted preference, toggled from the toolbar) decides.
