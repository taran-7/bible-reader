## Why

v1.3 PRD (6.8–6.11): читач не може позначити місце, виділити вірш кольором, записати думку чи продовжити читання там, де зупинився. Критерій етапу: закладки й нотатки переживають перезапуск і перебудову `bible.sqlite`.

## What Changes

- Окрема база користувача `userdata.sqlite` в Application Support (контейнер пісочниці): закладки, підсвітки, нотатки, останнє місце. Прив'язка — книга/розділ/вірш, без перекладу, тож дані переживають перебудову `bible.sqlite`.
- Закладки (FR-22): на вірш (контекстне меню) і на розділ (кнопка в тулбарі, ⌘D); секція «Закладки» вгорі бічної панелі, перехід одним кліком; прибрати — з меню.
- Підсвітка (FR-23): чотири кольори (жовтий, зелений, блакитний, рожевий) з контекстного меню для виділених віршів; видно фоном рядка; VoiceOver читає колір.
- Нотатки (FR-24): «Додати нотатку…» в контекстному меню, редактор у вікні; іконка біля номера вірша відкриває редактор; пошук у полі пошуку показує й нотатки з цим текстом (секція «Нотатки» над віршами); експорт усього в JSON і Markdown з меню «Файл».
- Останнє місце (FR-25): переклад, книга й розділ зберігаються при кожному переході; запуск відкриває їх.

## Non-goals

- Синхронізація, імпорт з JSON.
- Перерахунок нумерації для Синодального: вірш зберігається номером на екрані (таблиця відповідностей — v2.0, tech debt #1).
