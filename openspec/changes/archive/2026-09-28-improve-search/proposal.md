## Why

v1.2 PRD (6.4–6.7): пошук знаходить лише точні словоформи (tech debt #3), обрізаний до 200 результатів без лічильника і не дає звузити область. Критерій етапу: tech debt #3 закрито, пошук < 200 мс на всій Біблії (NFR-3).

## What Changes

- Морфологія (FR-18): слова запиту без лапок шукаються за основами. Англійська й російська — Snowball 3.0.1 (C, BSD-3, вшитий як ціль `CSnowball`); для KJV `-eth`/`-est` → `-es` перед стемером. Українська — легке відтинання закінчень, чеська — легкий стемер Dolamic & Savoy (Snowball не має цих мов). Імпорт будує `verses_stem_fts` з основ; запит стемиться тим самим стемером.
- Фільтр області (FR-19): панель над результатами — «Уся Біблія / Старий Завіт / Новий Завіт / <поточна книга>»; зміна перезапускає пошук.
- Усі результати (FR-20): «Знайдено: N» — повна кількість в області; сторінки по 100, наступна довантажується, коли прокрутили до кінця. Ліміт 200 прибрано.
- Фраза (FR-21): текст у лапках `"…"`, `«…»`, `„…“`, `“…”` шукається точною фразою (слова поспіль, точні форми) у `verses_fts`; можна поєднувати зі словами без лапок. Непарна лапка — звичайний символ.
- Підсвітка: у результаті показується весь вірш, підсвічені всі форми слів запиту (замість фрагмента `snippet`).
- NFR-3 (пошук): тест на реальній базі — найчастіші слова кожної мови й фраза < 200 мс.

## Non-goals

- Ранжування за релевантністю: порядок книг, як і раніше.
- Пошук з підстановкою (`любо*`), NEAR, OR.
- Час запуску (NFR-3, друга половина) — у `add-a11y-launch-checks`.
