# Core beliefs

- **Small scope, full loop.** A test-proven MVP beats many features that "seem to work".
- **The repository is the agent's source of truth.** What is not in the repo (decisions, constraints) the agent does not know. Decisions are written down in `docs/`.
- **Logic separate from UI.** Everything that can be verified lives in `BibleCore` and is covered by `swift test`.
- **Reproducible data.** The database is generated by a script from source files in the repo, not taken "from somewhere".
- **Maker ≠ checker.** Before a PR, the diff is reviewed by a separate agent.
