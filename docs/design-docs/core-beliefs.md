# Core beliefs

- **Маленький обсяг, повний цикл.** Краще MVP, доведений тестами, ніж багато функцій «наче працює».
- **Репозиторій є джерелом правди для агента.** Те, чого немає в репо (рішення, обмеження), агент не знає. Рішення записуємо в `docs/`.
- **Логіка окремо від UI.** Усе, що можна перевірити, живе в `BibleCore` і покривається `swift test`.
- **Дані відтворювані.** База генерується скриптом з вихідних файлів у репо, а не лежить «звідкись».
- **Maker ≠ checker.** Перед PR diff рев'ює окремий агент.
