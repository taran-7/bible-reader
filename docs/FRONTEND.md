# Frontend (SwiftUI)

- Вікно: `NavigationSplitView`. Бічна панель: 66 книг (СЗ/НЗ) мовою активного перекладу. Основна область: текст розділу з номерами віршів.
- Тулбар: перемикач KJV / Синодальний, ◀ ▶, вибір розділу, `.searchable`.
- Пошук: посилання → перехід; інакше список результатів з підсвіченим збігом.
- Копіювання: ⌘C і контекстне меню на виділених віршах.
- View не ходять у БД напряму, лише через `ReaderViewModel`.
